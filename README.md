## 📌 Project Overview

This project analyzes customer transaction data to identify patterns in **sales, revenue, customer demographics, product categories, and payment methods**.

The analysis was performed using **MySQL** for data exploration and business-focused SQL queries, with **Power BI** used to turn the results into an interactive dashboard.

### Business questions explored

- Which customer groups generate the most revenue?
- Which product categories have the highest sales?
- How does purchasing behavior vary by gender and age group?
- Which payment methods are used most frequently?
- Which category and customer segments contribute most to revenue?

## 🧠 SQL Highlights

The project includes SQL queries for:

- Data exploration
- Aggregation and grouping
- Revenue calculations
- Customer segmentation using `CASE`
- Category and gender analysis
- Age-group analysis
- Payment-method analysis
- Multi-dimensional analysis using `GROUP BY`

### Example: Revenue by Gender

```sql
SELECT
    gender,
    SUM(price * quantity) AS revenue
FROM customer
GROUP BY gender
ORDER BY revenue DESC;
```

### Example: Age Group Segmentation

```sql
CASE
    WHEN age BETWEEN 18 AND 25 THEN '18-25'
    WHEN age BETWEEN 26 AND 35 THEN '26-35'
    WHEN age BETWEEN 36 AND 45 THEN '36-45'
    WHEN age BETWEEN 46 AND 60 THEN '46-60'
    ELSE '60+'
END AS age_group
```
